# Eslate Technologies

Standalone React/Vite recreation of the Eslate Technologies website based on the supplied Airo preview recording.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build for production

```bash
npm run build
npm run preview
```

## Deploy

This is a normal Vite project and can be deployed to Vercel, Netlify, Cloudflare Pages, or any static web host.

### Important
- Replace the placeholder form submission in `src/main.jsx` with your email/API/backend when you are ready.
- Update phone number/content in `src/main.jsx` if required.
- The logo is recreated in CSS/text; replace it with the official logo asset if you have one.
